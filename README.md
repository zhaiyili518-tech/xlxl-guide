# XLXL 中文教程

XLXL 插件的产品首页与完整中文教程，适用于 zhaiyl.xlxl 1.2.0。

涵盖工程管理、代码编辑、诊断、信号追踪、Icarus 仿真、VCD 波形和 FPGA 构建。附可运行的计数器工程和四空格端口对齐示例。版本日志按次版本系列归并，见 [CHANGELOG.md](CHANGELOG.md)。

本站为无需构建的静态 HTML/CSS/JavaScript 网站，由 GitHub Pages 从 main 分支根目录发布。请保留 .nojekyll，确保示例工程中的 .xlxl 配置能原样提供。

网站本身无需登录；阅读进度和主题只保存在访问者浏览器中。
